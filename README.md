# Phase B: Sheet Design / One-time Payment Label v1

月謝袋ラベルと同じ50mm角の都度支払い用ラベル。

## サイズ
- 50mm × 50mm
- 印刷時は物理寸法固定
- PC/スマホの画面プレビューはレスポンシブ

## デザイン
- 白地主体
- 左端のみ都度支払い用アクセント色
- 桜風館
- チケット風の仮SVGアイコン
- 氏名
- 料金プラン
- 1回単価（「円 / 1回」と明記）
- 説明（空欄なら非表示）
- QR 24mm

## QR
- `member_id + plan_id`
- PAYMENT_ONETIME
- QR自体の装飾なし

## 確認ポイント
1. 月謝ラベルと並べて用途が直感的に区別できるか
2. 「1回あたり」の意味が誤解なく伝わるか
3. QR実機読取
4. 50mm角で情報量が多すぎないか
