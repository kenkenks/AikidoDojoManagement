# QR料金プラン候補制限パッチ

## 前提マスター
シート名:
`03_料金プラン選択ルール`

列:
- `member_type`
- `selectable_plan_id`

例:
- 一般 / P001
- 一般 / P002
- 子供 / P003
- 子供 / P004
- 家族３ / P011
- ビジター / P020

## 動作
1. QR生成画面で会員を選択
2. `01_会員マスタ.区分` を取得
3. `03_料金プラン選択ルール` から、その区分の許可plan_id集合を取得
4. QR種別（月謝/都度）の `会費タイプ` とAND条件で絞る
5. 候補だけを料金プランプルダウンに表示

候補が1件でも「自動決定ルール」ではなく、
マスターによる候補制限の結果として1件になります。

## 変更ファイル
- `gas/sheetContext.js`
- `gas/21_QrGeneratorOptions.js`
- `web/qr/qr_generator.html`
