## サイズ

- 会員カードと同一規格
- 印刷時は物理寸法固定

## デザイン
- 白地主体
- 左アクセントは青灰系
- 桜風館
- 指導者/先生の仮SVGアイコン
- 先生名
- 役職（空欄なら非表示）
- 先生ID
- QR 37mm
- 桜の仮マーク
