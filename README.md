# QR料金プラン候補抽出 共通ロジック修正

## 修正方針

家族だけの特別処理は追加していません。

すべての会員を同じ経路で処理します。

```text
01_会員マスタ.区分
  ↓
03_料金プラン選択ルール.member_type
  ↓
selectable_plan_id[]
  ↓
03_料金マスタ.plan_id
  ↓
QR種別に必要な 会費タイプ で絞る
```

## 重要

`03_料金マスタ.区分` は候補判定に使いません。

たとえば:

- 会員区分 `一般` → P001/P002
- 会員区分 `子供` → P003/P004
- 会員区分 `大学生` → P005/P006
- 会員区分 `家族３` → P011

P011の料金マスタ上の区分が `家族` でも問題ありません。
会員区分との対応は `03_料金プラン選択ルール` が担当します。

## 追加対策

会員区分・ルール区分は `NFKC` 正規化して比較します。
全角数字などの表記差による不一致を抑えます。

## 変更ファイル

- `gas/21_QrGeneratorOptions.js`
- `web/qr/qr_generator.html`

GAS変更を反映する場合は `clasp push` とWebアプリ再デプロイが必要です。
