# Phase B: Sheet Design / Monthly Bag Label v1

月謝袋の裏面貼付を想定した小型ラベル。

## サイズ
- 50mm × 50mm
- 印刷時は物理寸法固定
- 画面プレビューはPC/スマホ共通

## デザイン
- 白地主体
- 左端1.8mmだけ月謝色
- 桜風館
- 月謝QRアイコン
- 氏名
- 料金プラン
- 金額
- 説明（空欄なら非表示）
- QR 24mm

## QR
- 月謝用 `member_id + plan_id`
- quiet zone確保
- QRそのものへの装飾なし

## 確認ポイント
1. 月謝袋裏面に貼ったときの大きさ
2. QR読取
3. 氏名・金額が小さすぎないか
4. 50mm角で情報量が多すぎないか
5. インク消費が気にならないか
