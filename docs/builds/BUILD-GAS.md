# BUILD-GAS

## 1. Purpose

This document defines the build artifact contract for Google Apps Script (GAS) targets.

The repository source tree is not the deployment unit. A GAS deployment must use the
artifact produced by the Target Builder under `.build/`.

## 2. Build boundary

```text
Common Source
    |
    +-- npm run schema:build
    |
    +-- npm run target:build -- <gas-target>
            |
            v
      .build/<gas-target>/
            |
            v
       GAS deployment
```

`.build/` is the boundary between development source and deployable artifacts.

## 3. Targets

Current GAS target profiles are stored under `targets/`.

- `dev-gas`
- `demo-gas`
- `prod-gas`

Target-specific IDs, exclusions, and runtime settings belong to the target profile,
not to the common source.

## 4. Artifact structure

The Target Builder creates the following structure for a GAS target.

```text
.build/<gas-target>/
|-- gas/
|   |-- <GAS runtime files>
|   `-- .clasp.json
|-- web/
|   `-- qr/
|       |-- <Web files>
|       `-- runtime_config.js
`-- .target-build.json
```

### `gas/`

Contains the GAS files selected from the configured `sourceDir`.
Files excluded by the target profile must not be copied into this directory.

`.clasp.json` is generated for the selected target and identifies the GAS project used
by the artifact.

### `web/qr/`

Contains the Web files selected from the configured `webSourceDir`.
`runtime_config.js` is generated by the Target Builder and contains the target-specific
runtime configuration, including the GAS Web API URL.

### `.target-build.json`

Records build metadata such as the target, runtime, GAS deployment information,
copied-file counts, and excluded files.
