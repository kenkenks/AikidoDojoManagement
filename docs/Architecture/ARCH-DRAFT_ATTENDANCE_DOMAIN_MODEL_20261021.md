# ARCH-DRAFT｜出席管理の業務概念モデル（箱・饅頭・饅頭袋）

- 記録日：2026-10-21
- 状態：業務概念の整理／実装仕様は未確定
- 対象：桜風館・道場サポ（通常出席／紙の過去出席取込）
- 関連：`ARCH-DRAFT_TRAINING_SCHEDULE_20261021.md`（基本枠・イレギュラー枠）

## 1. 目的

稽古の**予定（稽古枠）**と、会員が実際に積み重ねる**稽古時間（H）**を区別する。特に、過去の紙の出席シートを取り込む際に、時間数を架空の稽古枠の個数に置き換えない。

## 2. 業務概念：「箱・饅頭・饅頭袋」

| 例え | 業務概念 | 意味 |
| --- | --- | --- |
| 箱 | 稽古枠 | 先生が時間・場所などを配置し、管理する稽古の枠 |
| 饅頭 | 稽古時間の基本単位（1H） | 会員が実際に稽古した量 |
| 饅頭袋 | 会員の稽古実績 | 会員が日々獲得したHの蓄積 |

- **先生は箱をどう並べ、どう使うかを管理する。**
- **会員は稽古で得た饅頭（H）を自分の袋に集める。**
- 箱の個数と饅頭の個数は同義ではない。

## 3. 稽古の基本単位

- 稽古の基本単位は **1H**。安全や運営上の事情も含めた単位である。
- 2Hの稽古枠は基本的に1H単位へ分解可能。
- 2H枠でも1Hだけ参加して帰る会員がいる。したがって「2H枠への参加＝必ず2Hの実績」ではない。
- 稽古枠の時間・構成と、個々の会員の実参加Hを混同しない。

## 4. 通常の出席と過去の紙シート取込

### 4.1 通常の出席

通常の稽古参加では、スケジュール上の稽古枠に参加し、その参加内容に基づいて実際の稽古時間を記録する。

```text
稽古枠（先生が管理）
    ↓ 参加
会員が実際に稽古したH
    ↓ 記録
会員の稽古実績（饅頭袋）
```

### 4.2 過去の紙シート取込

紙シートに記録されているのは、**会員・日付・稽古時間数（H）**であり、参加開始時刻や参加した稽古枠ではない。したがって、過去の枠や時刻を復元できない。

```text
紙シート：会員 ＋ 日付 ＋ H数
    ↓
稽古枠：不明（フリー）
    ↓
会員の稽古実績（饅頭袋）にHを記録
```

「フリー／不明」は**参加枠を特定できない状態**を指す。特定の時間帯や、連番付きの複数枠を意味しない。具体的なデータ表現（ID・NULL・別属性など）は未決定とする。

### 4.3 例

| 会員 | 日付 | 稽古枠 | 実参加H |
| --- | --- | --- | ---: |
| A | 例示日 | 14:30–16:30の2H枠 | 2H |
| B | 例示日 | 同じ2H枠 | 1H |
| C | 過去の記録日 | 不明（フリー） | 3H |

## 5. 紙シート取込の業務原則

1. 紙シートの **1マスは1H** を表す。
2. 紙シートの記録は **1日最大8H** を想定する。
3. H数は数量であり、稽古枠の連番ではない。
4. **3Hの実績を保存するために3個の架空の稽古枠を作らない。** `PAPER_UNKNOWN_SLOT_1`、`_2`、`_3` … という連番には、紙記録に基づく業務上の意味がない。
5. 過去の稽古時刻・稽古枠は、紙にない情報として推定・捏造しない。
6. 出席時間と会費計算は区別する。1Hと2Hが同料金となる運用があっても、実参加Hはそのまま記録する。

## 6. 現行実装とのギャップ（2026-10-21時点の調査結果）

紙取込では `PAPER_UNKNOWN_SLOT_1` と `_2` を用意し、同日の記録を `occurrence` 順に空きスロットへ割り当てている。このため3件目はブラウザ側で `ATTENDANCE_SLOT_CAPACITY_EXCEEDED` となり得る。

一方、共通の出席登録処理は、枠IDをマスタ整合・重複判定・取消処理などに使用している。**2枠制限の直接原因が紙取込側にあること**と、**枠IDへの構造的依存が共通処理にもあること**は分けて扱う。

仮想枠を8件に増やすことは現行方式の暫定回避策にはなり得るが、上記の業務概念を表現する恒久設計とはしない。
