# 紙出席簿読み取り共通化 第1段階

実施日: 2026-10-25

## 実装範囲

- P3-5～P3-9で検証済みの純粋ロジックを `paper_attendance_reader.js` として独立させた。
- 画像座標、OCR候補、400セル、手修正、日付集計、差分計画、登録レコード、差分登録オーケストレーションを公開する。
- CommonJSとブラウザglobalの両方で同じAPIを利用できる。
- 既存先生画面はまだ新モジュールへ接続せず、次段階まで挙動を完全に維持する。

## 検証

- 新旧モジュールの公開API一覧が一致すること。
- 日付正規化、画像縮小率、OCRセル割当、差分計画、登録レコード、紙面順空白化の結果が一致すること。
- 2時間確定済み・3時間希望時に、紙専用slot 3だけを1回送信すること。
- 既存の紙取込画面、OCR、差分登録、初期化、DTO回帰が維持されること。

## 未完成部分

- 先生画面はまだ従来のローカル実装を利用している。第2段階で共通モジュールへ切り替える。
- 会員画面、サーバー側主体判定、確認待ち保存、先生承認は未実装。
- API、Schema、Firestore、GAS、Cloud Run、Hostingには変更していない。
