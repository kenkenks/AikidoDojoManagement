# 審査管理 UIプロトタイプ

## 目的
ARCH-024「審査・昇級昇段管理」の画面仕様を検討するための
操作可能なHTMLプロトタイプ。

先生に実際に操作してもらい、画面構成や操作方法を確認する。

## ファイル
- index.html：審査管理画面のプロトタイプ

## 操作方法
index.html をブラウザで開く。

確認できる操作：
- 級審査・段審査の切り替え
- 審査予定日の選択
- 会員一覧の表示
- 会員詳細の確認
- 審査候補・受験登録の模擬操作

## 制約
- 会員情報・審査予定は架空データ
- Firebase / GASには接続しない
- 登録内容は保存されない
- 正式な審査資格判定は行わない
- 既存システムとは独立して動作する
