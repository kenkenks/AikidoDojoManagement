# TASK-QR-004 先生メンテQR発行

## Origin

- ITER-003 道場システム リリース準備
- STORY-QR-001 QR発行
- TASK-QR-001〜003

## Scope

1. 先生メンテ画面に「QR発行」導線を追加する。
2. 5種類のQRから発行対象を選択できる。
3. QR種別に応じた対象選択UIを表示する。
4. 必要なID・表示情報を取得する。
5. QR生成共通機能を呼び出す。
6. 対応HTMLテンプレートをプレビュー表示する。
7. 同一条件で再生成できる。

## QR selection

| QR種別 | 選択対象 | 初期値・補助 |
|---|---|---|
| 会員カード | 会員 | 会員検索／一覧 |
| 月謝 | 会員 → plan | 対象会員に利用可能なplan |
| 都度支払い | 会員 → plan | 対象会員に利用可能なplan |
| 道場 | 道場 | 現在の道場を初期候補 |
| 先生 | 先生 | ログイン中の先生を初期候補 |

## Policy

QRの発行履歴は持たない。

QRは既存IDから決定的に再生成できるため、
リリース初版では「再発行」は同一条件での再生成として扱う。

## Acceptance

- 先生メンテからQR発行へ遷移できる。
- 5種類のQRを選択できる。
- QR種別に応じた対象を選択できる。
- 必要なmember_id / plan_id / location_id / teacher_idを取得できる。
- 対応するQRシートをプレビューできる。
- 同一対象について何度でも再生成できる。
- ブラウザ印刷へ進める。

## Out of scope

- 発行番号
- 発行履歴
- 再発行理由管理
- 専用PDF出力
