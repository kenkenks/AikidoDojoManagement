# TASK-E2E-CLEAN-001 E2Eテストデータ クリーン処理

STATUS: 実装済・実環境確認待ち

## Origin

- ITER-003 道場システム リリース準備
- 実運用E2E確認時、過去のテスト入金・請求データが残っており、一周確認を継続できない。

## 目的

E2Eを初期状態に近い状態から再実行できるように、指定した会員に関係する会費データだけを残し、それ以外のテストデータを物理削除する。

## 対象シート

- `04_月次選択`
- `05_請求明細`
- `06_入金ログ`
- `09_決済エビデンス`
- `20_会費状態View`

マスタおよび `07_出席ログ` はこのTaskでは削除しない。

## 仕様

- 保持する `member_id` を複数指定できる。
- 削除開始前に、指定会員の `billing_group_id` と関連する `invoice_id` を収集する。
- 指定会員と同じ請求グループに属する会費データは、整合性維持のため保持する。
- 関連キー収集後、下流シートから順に不要行を物理削除する。
- 指定した `member_id` が `01_会員マスタ` に存在しない場合は削除を開始しない。
- 保持会員が0件の場合は削除を開始しない。

## 実行

GASエディタ等から次の形式で実行する。

```javascript
e2eCleanExceptMembers(["M001", "M005"]);
```

## Scope out

- 削除件数表示
- dry-run
- 論理削除
- 汎用Cleaner化
- UIからの実行

## 完了条件

- 指定会員に関係する会費データが残る。
- 指定会員以外の対象5シートのテストデータが物理削除される。
- CLEAN後にE2E運用確認を再開できる。

## 実行UI

スプレッドシートを開いたときの `道場管理` メニューから、
`E2Eテストデータ クリーン` を選択する。

残す `member_id` をカンマ区切りで入力する。

```text
M001,M005
```

キャンセル時は何も変更しない。
