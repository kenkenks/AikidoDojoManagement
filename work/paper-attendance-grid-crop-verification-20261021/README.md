# 20×20格子領域・初期切り出し検証

元画像に対し、検出した縦横21本、外周、四隅を重ねて確認した。

## 色

- 緑：20×20格子の外周
- 青：縦罫線21本
- 赤：横罫線21本
- 黄：四隅

## 結論

- 上端は時間見出しの直下、20行目の上辺に一致する。
- 下端は1行目の下辺に一致する。
- 左端は行番号欄を除外し、第1列の左辺に一致する。
- 右端は第20列の右辺に一致する。
- 四隅と21×21本の選択順にずれはなく、初期切り出しの変更は不要。

粗い投影位置から罫線交点への補正量は、X方向が平均2.937px・95%点14px・最大24px、Y方向が平均3.127px・95%点6px・最大6pxだった。この値は実線へ寄せるために既に適用済みの補正量であり、補正後の切り出し誤差ではない。

後段メッシュ補正後の残差は別指標で、縦罫線が平均0.79px・95%点4px・最大13px、横罫線が平均0.26px・95%点1px・最大7px。したがって残差は初期領域の取り違えではなく、後段の局所ワープ／測定段階に属する。
