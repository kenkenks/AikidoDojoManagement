# 縦交点算出 1/2縮小粗探索 PoC

実施日: 2026-10-21

## 実装方式

- 元画像をLANCZOSで1/2に縮小し、縦罫線追跡と交点の粗位置を算出した。
- 粗位置を元画像座標へ戻し、各交点を元画像の罫線上で半径10pxだけ局所探索した。
- 最終交点・境界曲線は元画像を参照して確定した。
- Coons補正、4区画画像生成、カード生成、記入判定は変更していない。

## カード確認

- カード361・362・381・382はいずれも記入候補として保持された。
- ブラウザ表示で文字の欠け・隣接セルの明瞭な混入は認めなかった。
- statusまたはink scoreが基準から変わったカードは45枚あり、対象4枚も含まれる。検出結果は維持したが、画素完全同一ではない。

## 判定

1/2縮小は、記入セル27/27と補正品質を維持しながら縦交点算出を約4.4倍高速化できた。ただし441点中224点に最大3pxの差、45カードにスコア差があるため、このPoCだけで既存処理を置換できるとは判定しない。

1/4縮小は実施しなかった。1/2で既に局所差が観測されており、先に許容誤差と複数画像での再現性を確定する必要があるためである。
