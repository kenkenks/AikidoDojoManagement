# 紙出席画像前処理プロトタイプ 最終評価

評価日: 2026-10-21

## 実装

- 21本の縦罫線を、局所交点ごとではなく上端から下端まで連続追跡した。
- 狭い縦線の濃さ、周辺との差、傾斜と曲率の連続性を動的計画法で評価した。
- 連続経路と21本の横罫線の交差位置を、441交点のX座標へ反映した。
- 各列の探索領域を半セル未満に制限し、列IDの交換を禁止した。
- メッシュ補間、横罫線追跡、差分処理、OCR、UI、業務処理は変更していない。

## 未解決事項

1. 評価は帳票1枚のみで、異なる撮影角度・解像度・筆跡への一般化は未確認。
2. 自動測定の最大残差は21px。外周および文字と罫線が重なる地点を含むため、個別原因は未分類。
3. Python試作を現在のNode.js Cloud Run実行経路へ載せる方式は未確定。OCR・UIを変更しない今回の範囲では接続していない。
4. カード候補判定は今回の変更対象外。全400セルの分類件数は変化したが、既知の記入27セルはすべて維持された。

本評価をもって画像補正アルゴリズムの追加研究は終了する。次工程では、この確定した補正・カード生成処理を実行環境へ移植する際のランタイム構成を決定する。
