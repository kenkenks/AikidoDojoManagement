# 紙の出席記録 AI解析検証

検証日：2026年10月19日

## 概要

20×20の手書き出席記録について、
Gemini 2.5 Flashによる画像解析を5回検証した。

## 主な結果

- 記入セル検出：27/27件（第1〜4回）
- 帳票全体の日付正読：最高18/27件
- 第5回の拡大再認識：6/7件
- 誤読の自動検出には課題が残る

## 資料構成

- TECHNICAL_REVIEW.md：技術総評
- images/：検証画像
- results/：実験結果JSON、比較資料、画像台帳
- scripts/：実験スクリプトの保管用コピー

## 注意事項

- 第5回は拡大画像と追加指示を同時に変更した実験。
- 第5回の6/7件は帳票全体の認識精度ではない。
- 日付の自動確定は行わず、人間による確認を前提とする。
- scripts/は保管用。実行時には参照パスと認証環境の確認が必要。
